## 🌿 About

**diwaznV2** is a Minecraft-inspired custom theme for Vencord, created by **diwazn**.

Transform your standard Discord interface into a unique Minecraft-inspired experience.

## 🧱 Features

- 🌳 Minecraft-inspired aesthetic
- 🟩 Custom color palette
- 👤 Redesigned profile layouts

- ✨ Unique visual styling
- 🎨 Custom CSS design

## 📥 Installation

1. Install [Vencord](https://vencord.dev/).
2. Download `diwaznV2.theme.css`.
3. Open Discord settings.
4. Navigate to **Vencord → Themes**.
5. Import the CSS file.
6. Enable **diwaznV2**.
