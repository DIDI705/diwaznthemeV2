## 📥 Installation

1. Install [Vencord](https://vencord.dev/).
2. Download `theme.css` from this repository.
3. Open Discord settings.
4. Navigate to **Vencord → Themes**.
5. Import your local theme file.
6. Enable the theme.

## ⚙️ Customization

The theme can be customized directly through its CSS code.

```css
:root {
    --background: #101018;
    --accent: #a78bfa;
    --text-color: #e6e6f0;
    --border-radius: 12px;
}
```
